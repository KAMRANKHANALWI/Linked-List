# Linked List Problem Patterns

## 1. Pointer Reversal

Problems

- Reverse Linked List
- Reverse recursively

Idea

prev <- curr -> next

---

## 2. Dummy Node

Problems

- Merge Lists
- Add Two Numbers
- Remove Nth Node

Idea

Create a fake node before head.

Removes edge cases.

---

## 3. Slow & Fast Pointer

Problems

- Middle Node
- Detect Cycle
- Start of Cycle
- Delete Middle

Idea

slow += 1

fast += 2

---

## 4. Two Pointer Gap

Problems

- Remove Nth Node
- Palindrome

Idea

Maintain fixed distance.
